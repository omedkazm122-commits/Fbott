# پۆرتالی وەرگرتن - Telegram Mini App

تطبيق حساب القبول الجامعي في العراق، جاهز للعمل كـ Telegram Mini App.

## خطوات الرفع على GitHub Pages

1. أنشئ repository جديد على GitHub (Public).
2. ارفع كل ملفات هذا المجلد إليه (خصوصاً `index.html`).
3. من إعدادات الـ repo:
   Settings → Pages → Source: اختر `main` branch و `/ (root)` → Save
4. انتظر دقيقة، بعدها يظهر لك رابط بهذا الشكل:
   `https://<username>.github.io/<repo-name>/`
5. خذ هذا الرابط وضعه في BotFather:
   `/mybots` → اختر بوتك → Bot Settings → Menu Button → Configure Menu Button → ألصق الرابط
